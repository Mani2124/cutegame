# One Rose, Every Language 🌹❤️

**Two separate layers:**
1. Foreground: a red rose (petals, stem and leaves) formed from multilingual "I love you" text.
2. Background: pink mini hearts float from bottom to top and settle into a large heart outline behind the rose, then repeat slowly.

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public repository named `love-rose`.
2. Upload `index.html`, `style.css`, `script.js` at repository root.
3. Settings > Pages > Deploy from a branch > main > /(root).
4. Share `https://YOUR_USERNAME.github.io/love-rose/` after deployment.

Note: This is a stylized text rose and uses a curated set of languages rather than every language in existence.
